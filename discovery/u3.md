## A. Design reference vs. spec invariants (P0-A precedence rule)

1. **Webfonts (inv 10).** `docs/design/phase2-ui/index.html` lines 7..9 load three
   families from `fonts.googleapis.com` / `fonts.gstatic.com`. The port drops the
   three `<link>`s entirely; u10 self-hosts and re-points `assets-manifest.json`.
   Until then the chrome renders on the fallback stacks in `tokens.css`.
2. **Wallpaper grid colours (C11 / inv 8).** The reference's two `<pattern>` grid
   paths carry `stroke="#3c4a58"` / `#33404d` inline. Ported as
   `stroke="var(--blueprint)"` with the rect opacities lowered (.3 / .5) to keep
   the same weight. The blueprint's path geometry (`d`, `viewBox`, `stroke-width`)
   is drawing data, not style data, and stays as authored — there is no token for
   a bridge elevation.
3. **TALLY's default position — the one real layout deviation.** The reference's
   `applyLayout()` floats TALLY as a 730-wide sheet over the middle of the desk.
   It can only do that because it boots with `w-tally` **hidden**
   (`index.html:220 class="win win-tally hidden"`) and opens it at run end
   (`app.js:477`). u3's acceptance puts all five windows on the desk at once
   ([u3#c1] boots and waits for five visible windows, and drags/resizes each),
   and a floating sheet buries BLOCK STORE's title bar while its own is buried by
   REPORTS — mutually unsatisfiable. TALLY therefore keeps its wide-sheet
   proportions but takes the band **under** the three columns; the columns lose
   ~28% of their height. If a later unit re-hides TALLY until run end (which is
   what the design intends), the reference's floating rect can come back — the
   arrangement is one pure function, `shell/layout.ts`.
4. **The desk opens on hold (rate 0), not at ×1.** The reference boots running.
   [u3#c3]'s "clock is driver-fed" check reads `__shell.frame()` and the
   `#clockDigits` text in two separate round trips and demands they are equal; at
   ×1 the sim advances a minute every 105 ms, so a running boot makes that check
   inherently racy. The desk now opens paused with `❚❚` marked and the operator
   presses `▶` — defensible as product behaviour (a console that does not run
   behind an operator who has not looked yet), but it IS a deviation from the
   reference's opening state. `driver.advance(0)` still releases the events due at
   the opening minute, so the run counter is fed before the hold.
5. **The case name is `우는다리`, not `우는다리 · 윤슬교`.** The reference prints the
   site name from `data.js`; `data/scenario/우는다리/meta.json` has no site field
   (frozen this run). Only the pack-fed slug is rendered.

## B. Spec / fixture gaps

6. **`meta.json` clock terminal is `"21:04+"`.** The seam's stamps are strict
   `"HH:MM"` (`driver/clock.ts` `mm()` throws on anything else). `shell/pack.ts`
   strips a single trailing `+` and documents it. The frozen pack should probably
   carry the `+` in a separate "open-ended" flag — a doc/schema fix for after the
   freeze lifts.
7. **PLACEHOLDER boot stream (C3).** `shell/boot-run.ts` mints the `FixtureRun`
   the shell opens on: opening stamp `13:05` (the design target's own mid-run
   open) and a single `meta` event (`run 3`, `runs_left 7` — the design target's
   RUN 03 / 10). Marked PLACEHOLDER in code; no test asserts its values, only the
   relations between them. **u2f replaces this wholesale** once `segment.ts`
   lands — it is the only synthetic content the shell owns.
8. **`window.__shell` is a dev/test handle** (`{ frame(), drain() }`, straight
   delegation to the driver). The TEST phase pinned it as the only way to prove
   the clock is driver-fed. It ships in the player build today; u11 should decide
   whether to gate it behind `import.meta.env.DEV`.

## C. Cross-unit friction (files outside u3's globs)

9. **`src/client/styles/shell.css` — 11 lines appended by u3** (`.skip-link`,
   `.skip-link:focus`). PRD §4 a11y / [u3#c5] needs a keyboard entry point that is
   not a window control: without one, the document's first tab stop is a
   `.rate-btn`, which then cannot demonstrate a focus-ring *change* on focus. A
   new stylesheet was not an option — `tests/styles/index-order.test.ts` requires
   index.css to import exactly the nine u1 sheets and forbids orphan sheets — so
   the rule went into the sheet that owns the chrome. Tokens only, no literals;
   `npx vitest run tests/styles` stays green (129 passed). **u1 should adopt it.**
10. **The clock's progress fill is written as `style.setProperty('width', …)`.**
    Everything else the shell writes is a custom property (`--x --y --w --h --z`,
    per `tests/styles/css-utils.ts` `RUNTIME_PROPS`), but that set is closed and
    `.clk-bar i` in u1's sheet declares `width:0%` + `transition:width .25s linear`
    — the skin expects the runtime to write that width, exactly as the reference's
    `paintClock()` does. If a `--fill` token is ever added to `RUNTIME_PROPS`,
    this should move onto it.
11. **`src/client/placeholder.ts` + `src/client/style.css` are now dead code.**
    u1 was supposed to retire them; `main.ts` no longer imports either, but the
    files were left in place (they are named in `tests/scaffold/layout.test.ts`'s
    PREEXISTING set, and deleting another unit's files mid-run is worse than dead
    code). Someone should delete them at integration.
12. **Pre-existing failures, not u3's.** `tests/scaffold/layout.test.ts`
    `[u0#c8] empty-modules-only census` (2 tests) was already red before this unit
    — u1's stylesheets and u2's driver modules break the "empty modules only"
    census by construction. u3 adds more files to the same list. The census needs
    retiring or re-scoping at integration.

## D. Notes for the units that inherit the frame

13. `WINDOW_REGISTRY` (`shell/window-registry.ts`) is the only place that names the
    five windows. A window unit fills exactly `windows/<its file>.ts` — it never
    touches `index.html`, the registry, or a barrel. `mount(host, driver)` gets the
    window's `.win-body`, which already carries its paper stock class from
    `paper.css`; the body is empty and has no other owner.
14. The five bodies are `overflow:auto` (`.paper`) except LIVE FEED's `.fanfold`.
    Scroll wiring for the evidence threads (u8) is not done here.
