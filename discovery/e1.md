# e1 — discovery

## 1. The unit has no `design.md` / `spec.md`

`.claude/super/units/e1/` did not exist in this worktree, and the main repo's
`.claude/super/units/` has directories for `u0 u2 u3 u4 u5 u7 u8 u9 u10 u12 u13`
— nothing for the `e*` wave. The unit contract used by TEST is therefore the
unit JSON passed in the prompt plus the read scope it names
(`docs/contract-engine-composer.md` §4/§4.1, `docs/contract-calls.md` §6,
`data/scenario/우는다리/temperament.json`, `data/policy/report-guidance.json`),
cross-checked against `docs/plan-engine-build.md` §3 row e1 and §4a row e1.

**Integrator action:** the unit-artifact writer skipped the `e*` wave. Not fixed
inline — a TEST agent minting its own design doc is exactly the drift the
artifact writer exists to prevent.

## 2. The unit ships two modules but the gate names only one test file

`plan-engine-build.md` §4a gates e1 on
`npm test -- tests/shared/temperament.test.ts`, and the unit's `file_globs`
allow only `tests/shared/temperament.*` — yet the unit's own title ships
**two** modules, `src/shared/temperament.ts` **and**
`src/shared/report-guidance.ts`.

A sibling `tests/shared/report-guidance.test.ts` would sit outside both the glob
and the gate, so a broken report-guidance renderer would ship green. The
report-guidance suite therefore lives inside `tests/shared/temperament.test.ts`
(suite `[e1] renderReportGuidance`). The file name under-describes its contents
by one module — deliberate, and cheaper than an ungated module.

**Integrator action:** either widen e1's gate to `npm test -- tests/shared` or
accept the combined file. Not resolved here.

## 3. `ReportGuidance` has no declared home

`contract-engine-composer.md` §3 types `ComposerDeps.reportGuidance` as
`ReportGuidance`, and no module declares that type — `src/shared/datapack.ts`
covers the datapack only, and `data/policy/report-guidance.json` lives outside
the pack by design (contract-calls §4). The suite pins the type to
`src/shared/report-guidance.ts` (`export type ReportGuidance`) as the natural
home, since e5's `ComposerDeps` will need it by name.

If S/윤석 want it in `contracts.ts` instead, that is a one-line move plus a
one-line edit to case `[e1] placement (c)`. Flagged rather than assumed.

## 4. The temperament prose shape is still open — and the suite is built to stay silent about it

`contract-engine-composer.md` §4.1 is explicit that the shape is S + D's and
"the one item in this contract a work unit must not resolve on its own", with
the first real rendering a **paper check, not a unit test**. So the suite
asserts only the four §4 invariants plus two shape-neutral properties:

- the output is a **function of the pack** (a constant string satisfies all four
  invariants on its own — differing dispositions differ, clause count changes
  the output, and no authored `default_disposition`/`condition`/`defeat_condition`
  is dropped), and
- the source carries a **provisional marker**, which §4.1 requires.

The header check (invariant 4) accepts any of `[…]`, `【…】`, a markdown heading,
or a bold line — the forms used by the prompt templates and by the only
exemplar, `tools/probe/fixtures/temperament/k1.md`. It does not pick one.

**Consequence:** when S + D land the authored shape, the shape is asserted by a
paper check and possibly a golden; none of these 36 cases should need to change.

## 5. Read-scope gap: the prompt templates were needed and were not in scope

Invariant 4 says the slot is bare, and invariant 4's premise cannot be asserted
without looking at the templates. The scope list named only
`docs/contract-engine-composer.md` §4.1, `docs/contract-calls.md` §6, and the two
data files. Opened additionally, sections only:

- `proxy/prompts/judgment/base-v0.4.md` and `proxy/prompts/reporter/base-v0.2.md`
  — to confirm `{TEMPERAMENT}` really is bare (it is: alone on its line, blank
  line above, in both).
- `proxy/prompts/reporter/user-v0.2.md` — which showed the mirror-image fact for
  the *other* slot: `{REPORT_GUIDANCE}` sits directly under a `[보고 지침]`
  header the template supplies. So `renderReportGuidance` must **not** render a
  header, where `renderTemperament` **must**. The unit title calls both slots
  "bare"; only `{TEMPERAMENT}` is. Case `(h)` pins the difference.
- `src/shared/contracts.ts` §`ReporterSlots`/`JudgmentSlots` — to confirm both
  cross the wire as `TEMPERAMENT: string` (already-prose), which is what makes
  invariant 1 a byte comparison rather than a deep-equal.

`npx vitest` fails at config load (`Cannot find package 'vitest'`) until
`npm ci` runs in the worktree. Ran it here; `package.json`/`package-lock.json`
untouched (both frozen). Worth doing in the worktree setup step rather than
once per agent.
