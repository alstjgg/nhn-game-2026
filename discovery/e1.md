## 4. The temperament prose shape is still open — and the suite is built to stay silent about it

`contract-engine-composer.md` §4.1 is explicit that the shape is S + D's and
"the one item in this contract a work unit must not resolve on its own", with
the first real rendering a **paper check, not a unit test**. So the suite
asserts only the four §4 invariants plus two shape-neutral properties:

- the output is a **function of the pack** (a constant string satisfies all four
  invariants on its own — differing dispositions differ, clause count changes
  the output, and no authored `default_disposition`/`condition`/`defeat_condition`
  is dropped), and
- the source carries a **provisional marker**, which §4.1 requires.

**Correction (integ-fix pass):** the paragraph above described the test as
accepting four header forms without picking one; the ratified spec (A4) had
already picked one — `/^\*\*.+\*\*$/`, the bold-line style of the only
exemplar, `tools/probe/fixtures/temperament/k1.md` (decision 6) — and the
shipped code (`HEADER = '[기질]'`) matched none of A4's literal assertions. Both
the renderer and the test are now re-aligned to A4/decision 6: the renderer
emits `**너의 기질 — 이것은 협상 대상이 아니다.**` and the test's `HEADER_LINE` is the
single regex A4 specifies.

**Consequence:** when S + D land the authored body prose, the shape is
asserted by a paper check and possibly a golden; the header itself is no
longer open — it is spec, not just an exemplar.
