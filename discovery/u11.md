## Seam friction

1. **The DEV debug pane steals the pointer over the desk's bottom-left quadrant.**
   `vite.config.ts` folds `__DEBUG_PANE__` to `mode !== 'production'`, so every
   e2e host except `preview` boots with u9d's pane at `left:0; bottom:0;
   max-width:46vw; max-height:42vh`. LIVE FEED is 339×692 at 14,94, so its grip
   (337,770) and the lower third of its body are under the pane and a press
   there lands on the pane's own table. This is the same class of harness state
   C14/C15 already rule for captures, not a port defect: with the pane hidden,
   u3's resize and raise oracles pass unchanged. Fixed test-side in
   `e2e/fixtures/dev-surface.ts`; no production module touched.

2. **Font payload on the finished desk — owner u10.** First render pulls 50 of
   the 492 shipped slices, ≈1.05 MB. Subset loading is working (10 % of the
   sheet, every slice justified by rendered text, all `font-display: swap`), but
   u10's absolute budgets (24 files / 300 KB) were calibrated on an empty desk
   and no longer measure slicing. Re-aimed to the property; the absolute number
   is routed to u10 as a deploy question.

3. **C18 — the reporter's 6.8–10 s has no `waiting.for='report'` line, and that
   is faithful to the reference.** `docs/design/phase2-ui/README.md:58-60` spends
   the report call on the ~9 s TALLY count-up ([u7#c2]: "the count-up pacing
   absorbs the report call"), and `fixtures/woodari-run03.ts:152` uses one
   `WAIT_FOR = 'judgment'` for every wait row. The latency describe therefore
   asserts the client property C18 is about — whatever wait is open holds past
   9 s, survives 30 s, never becomes dead UI — plus the count-up case. No pacing
   or seam redesign, and nothing binds to fixture content (C3).

4. **AGENT FILE overflows its window at 1280×800 — owner u4, reported only.**
   `#w-file` is 375×692 while `.win-body` holds 956 px, so the fourth slot and
   DEPLOY are below the fold and reached by scrolling. No window is off-screen,
   so C9 / §7 #9 still hold; recorded because the reference shot shows board and
   button in one view.
