## 1. 네 경로 실측 (rev.2 경제)

재파견 비용 20/25/40 · 미달성 감액 1/3 · 시작 토큰 60 · 컨텍스트 상한 12.

| 경로 | 최종 토큰 | 장부 | 컨텍스트 | 양식 수정 | 엔딩 |
|---|---|---|---|---|---|
| **P1** 전부 승인 | 61 | 5 | 6/12 | 0회 | C |
| **P2** 정석 (매판 정답 지목) | **190** | 2 | 6/12 | 0회 | A′ |
| **P3** 완전 공략 (「입은 손실 v2」 장착) | **190** | 1 | **10/12** | 1회 | **A** |
| **P4** 오지목 반복 | 65 | 3 | 6/12 | 0회 | C |

```bash
# P1 전부 승인
printf '\nd\na\n\n\nd\na\n\n\nd\na\n' | node index.mjs
# P2 정석 (매 라운드 정답 지목)
printf '\nd\nr\n1\n\nd\na\n\nd\nr\n1\n\nd\na\n\n\nd\nr\n1,2\n\nd\na\n' | node index.mjs
# P3 완전 공략 (R3 진입 시 e → 4 → 3 으로 「입은 손실 v2」 장착)
printf '\nd\nr\n1\n\nd\na\n\nd\nr\n1\n\nd\na\n\n\ne\n4\n3\nx\nd\nr\n1,2\n\nd\na\n' | node index.mjs
# P4 오지목 반복
printf '\nd\nr\n3\n\nd\nr\n1\n\nd\na\n\nd\nr\n2\n\nd\nr\n1\n\nd\na\n\n\nd\nr\n1\n\nd\na\n' | node index.mjs
```

### 읽을 점

**① 검산의 보상이 역전에서 정상으로.** rev.1에서는 전부 승인(100)이 오지목(65)보다
부유해 "감사하면 손해"였다. 재파견 비용 하향(30→25, 50→40)과 미달성 감액 강화(1/2→1/3)로
**정석 190 ≫ 전부승인 61**이 됐다.

**② 전부 승인 경로도 이제 막힌다.** P1은 R3에서 `(재파견 비용 40 토큰 — 잔액 21.
승인만 가능)`에 걸린다. 대충 하면 **고칠 여력 자체가 사라진다**는 압박이 생겼다.

**③ A′ → A를 가르는 것은 여전히 양식 한 장.** P2와 P3의 차이는 R3 진입 시
「입은 손실 v2」(컨텍스트 4)를 장착했는가뿐. 토큰은 같고 엔딩이 갈린다.

**④ 컨텍스트가 실제 결정이 됐다.** P3는 10/12를 쓴다 — 「입은 손실 v2」를 넣으려면
다른 칸을 v1로 유지해야 한다. 남은 여유 2로는 어떤 v2도 못 넣는다.

## 2. 컨텍스트 제한 검증

상한 12, 시작 편성 6 (결과요약 v1·2 + 미달성 v1·2 + 도구 v1·2).

| 편성 | 합계 | 결과 |
|---|---|---|
| 시작 (v1 × 3) | 6 | 여유 6 |
| 미달성 v3(5) + 도구 v2(4) + 요약 v1(2) | 11 | 여유 1 — **더 못 넣음** |
| 위 상태에서 시각 기록 v1(2) 추가 시도 | 13 | `✗ 초과` 표시, 선택 거부 |
| 4칸 전부 v2 (2+4+4+4) | 14 | 애초에 불가 |

```
  이 칸에 쓸 수 있는 컨텍스트: 1
  1) 시각 기록 [v1] · 2  ✗ 초과
  2) 시각 기록 [v2] · 4  ✗ 초과
```

**"강한 것만 장착해서 클리어" 전략이 실제로 봉쇄된다.** 결정이
"무엇을 넣을까"에서 **"무엇을 포기할까"**로 바뀌었다 — 넓게 보되 얕게 vs 좁게 보되 깊게.
