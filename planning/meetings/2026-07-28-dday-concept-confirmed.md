# 2026-07-28 미팅 — DDAY 컨셉 확정

## 결론

- **DDAY** 컨셉으로 확정
- **Scenario**: "테러리스트의 전화"의 축소 버전
  - 선정 이유: 공간 이동 없이 전화 및 CCTV를 통해서만 정보 수집하기 때문에
    텍스트 추리물에 적합
  - 축소 이유: Agent prompting이 너무 복잡해짐
- **게임 컨셉**
  - 하나의 task를 agent가 성공할 수 있도록 프롬프팅하는 게임
  - 사건의 숨겨진 진실을 찾아내는 추리 게임
  - 에이전트의 행동을 조종하는 것이 아니라 타임라인 보고서 및 직접 작성
    보고서에서 추출한 '사실' 등을 주입해서 에이전트의 '판단'을 변화시키는 게임
- **Phase-2** (후순위로 구현하지 않음)
  - 두 개 이상의 문장을 컴팩트해서 새로운 문장을 넣는 기능
  - 프롬프트의 길이에 제한을 두는 기능

## 시나리오 축소 방안

### 검토 내용

- 인물 수 줄이기
- 숨겨진 사실(T) 줄이기
- 실패 게이트(G) 줄이기

### 축소 목적

- 데모를 하면서 의도대로 에이전트가 동작하지 않았던 부분을 시나리오 축소를
  통해서 해결하고자 한다
- 명확하게 에이전트가 왜 실패했는지, 왜 성공했는지를 알 수 있게 한다
