## 0. 이름 — Darkest Context

'에이전트 아레나'는 핵심을 빗나간다 — 이 게임은 대전장이 아니라 **여정과 관전**이다.
새 이름은 레퍼런스 오마주 위에 에이전트 뉘앙스를 얹는다:

**Darkest Context (다키스트 컨텍스트).** 관전 드라마의 원형인 Darkest Dungeon을 그대로
가리키면서, 그 게임의 스트레스에 해당하는 우리 시그니처 자원 — **컨텍스트 게이지** —
를 이름이 품는다. 게이지가 차오를수록 판단에 들어가는 입력이 어두워지고(오염),
100%에서 정신을 놓는다. "가장 어두운 컨텍스트"가 곧 이 게임의 위기 상태다.

검토한 대안: Slay the Prompt(StS 오마주 — 런 구조는 빌렸지만 게임의 얼굴은 아님),
For the Prompt(FTK 오마주 — 동일). 슬러그: `darkest-context`.

## 1. 한 줄 컨셉과 코어 루프

Prompt·Skill·MCP 카드를 드래프트해 **3–4기의 AI 에이전트 파티**를 조립하고, 분기형
선형 맵을 자동 전진시키며, 타일 이벤트를 파티가 **스스로 판단해** 헤쳐나가는 것을
지켜보는 로그라이크. 싸우고 푸는 것은 플레이어가 아니라 플레이어가 빚은 에이전트들이다.

플레이어의 동사: **선발 · 드래프트 · 장착 · 분기 선택 · 관전.** 한 글자도 타이핑하지
않는다 (멤브레인).

```
영웅 3–4기 선발
  → [ 자동 전진 (잡담·인선 회의 + 다음 이벤트 선발사)
      → 타일 이벤트 (파티가 판단, 플레이어는 관전)
      → 보상 → 강제 배분·장착 (플레이어의 퍼즐) ] × N타일
  → 보스전 — 나처럼 카드로 조합된 상대 에이전트 파티
```

## 2. 런 구조 — 맵

- **분기형 선형 맵.** 타일 한 줄 + 2–3회 분기 (StS 맵의 선형 압축). 분기 선택이 빌드와
  상호작용한다 — "언변 파티니 탈옥 분기로 간다."
- **자동 전진 (확정, 07/22).** 파티가 스스로 걷고 타일에 안착하면 이벤트가 발화한다.
  플레이어 입력은 분기점에서만. 걷는 연출이 LLM 호출 지연을 숨기는 자연 휴지다.
- **페이싱 하드 룰:** 첫 60초 안에 첫 이벤트 도착. 1번 타일은 강제 이벤트.
- 기획은 **최대 스펙**으로 잡는다 (07/22 합의). 데모 슬라이스는 데모 PRD에서 자른다.

## 3. 파티와 성장

**로스터.** 런 시작 시 영웅 명단에서 3–4기 선발. 전원 같은 베이스 모델 — 모델 티어는
파워 축이 아니다. 각 영웅은 저작된 default prompt(성격)와 직업·능력치(포인트 바이
총합 60)·기본 Skill로 갈리고, 시작 파워는 동등하다. 파티 구축의 결정은 티어표가 아니라
**구성**이다. 로스터 4기와 default prompt 전문: [예시 스펙 §2](./agent-arena-examples.md).

**카드 3분류 — Prompt · Skill · MCP (07/25 확정).** 구현은 셋 다 같다 — 캐릭터 시트
(시스템 프롬프트)에 문장이 추가된다. 게임 내 정의가 다르다:

| | 정체 | 추가되는 것 | 예 |
|---|---|---|---|
| **Prompt** | 캐릭터 내부 — 성격·판단 성향·능력치 | 순수 프롬프트 문장 | 「겁이 없다」 「원한」 |
| **Skill** | 몸에 익힌 행동·기술 | 행동을 서술하는 skill prompt | 「방패 올리기」 「이단 베기」 |
| **MCP** | 소지품 — 아이템·스크롤·도구 | 도구를 서술하는 skill prompt | 「화염 두루마리」 「자물쇠따기 도구」 |

한 줄 규칙: **성격이면 Prompt, 익힌 기술이면 Skill, 손에 쥔 물건이면 MCP.** Skill은
훈련의 결과라 캐릭터에 남고, MCP는 물건이라 유닛 간 이동·거래·소모가 자유롭다.
어느 쪽이든 skill prompt는 판단 재료일 뿐, 행동·수치의 **집행은 항상 엔진이다** (§6-3).
MCP는 장착 UI에서 "에이전트에 도구를 연결하는" 플러그 연출로 테마화한다 — 아이템
상점이 곧 MCP 마켓이고, 심사용 어필(AI 오케스트레이션 어휘)로도 살아난다.

**인벤토리.** 파티 공용 가방 없음. 유닛별 Prompt 3 · Skill 2 · MCP 3 슬롯 (수치 가변,
확장 아이템 여지). 슬롯이 꽉 찬 상태의 **강제 배분** — "누구의 무엇을 버릴 것인가" —
이 이 게임의 반복 퍼즐이다.

## 4. 자원 2종

**토큰 = 화폐.** 전투·과제 보상으로 획득하고, 상점(MCP 구매)·뇌물 등에 지출한다.
판단 호출마다 소모시키는 스태미너안은 검토 후 기각 (07/25) — 압박 자원은 컨텍스트
게이지 하나로 충분하고, 두 번째 소모 자원은 구현·튜닝 비용 대비 효용이 낮다.

**컨텍스트 게이지 = 유닛별 스트레스.** 다키스트 던전 스트레스의 에이전트식 번역이자
게임 이름의 유래. 실제 컨텍스트 윈도우나 실제 환각이 아니라 **엔진이 관리하는 수치**다:

| 구간 | 효과 |
|---|---|
| ~40% | 없음 |
| 40–70% | 연출만 — 응답 지연 연기, 말풍선 말더듬 |
| 70%~ | **엔진이 그 유닛의 상황 요약에 노이즈 주입** — 없는 적이 보이고, HP를 잘못 안다. LLM은 오염된 입력으로 정직하게 판단하므로 환각처럼 보이지만, 오염의 양과 종류는 엔진이 결정 → 레벨 디자인 가능 |
| 100% | 그 턴 판단권 상실, 직업 기본 행동 강제 |

예 — 게이지 74%의 모데카이: 노이즈가 적 HP를 실제의 절반으로 보여주고, 「과신」 기질과
결합해 "수치상 이미 끝난 싸움이다"라며 화염 두루마리를 아끼고 맨몸으로 돌진한다.
귀속 리포트는 `because: [mordecai.default]` + 게이지 아이콘으로 원인을 정확히 가리킨다.

**휴식 3종:** ① 생각정리 — 게이지 50%p 감소 (엔진 수치 조정 + 연출). ② 인벤토리 정리 —
Skill·MCP 삭제·재배치, 담당 변경. ③ **Clear** — 게이지 0 초기화, 대신 장착 Prompt 1장
무작위 망각 ("기억까지 지워진다"). 안전한 정리 vs 도박성 Clear의 긴장.

## 5. 타일 카탈로그

상세 예시(호출 스키마, 턴 워크스루, 문지기 프롬프트, 회의 엔진)는
[예시 스펙 §4](./agent-arena-examples.md). 요약:

| 타일 | 참여 | LLM 호출 | 보상 | 강제 배분 |
|---|---|---|---|---|
| 1대1 전투 | 선출 1기 (인선 회의) vs 몬스터 1 | 인선 1콜 + 턴당 1콜 | 토큰 + 카드 1 | ✔ |
| 다대다 전투 | 파티 전체 | 유닛별 병렬, 턴당 1벽시계콜 | 토큰 + 카드 3택1 | ✔ |
| 보스전 | 파티 전체 vs 상대 에이전트 파티 | 양측 병렬 | 대량 토큰 + 카드 | ✔ |
| 탈옥 | 선출 1기 (인선 회의) vs 문지기 | 인선 1콜 + 왕복 대화, 최대 6합 | 통행 + 토큰 | — |
| 퍼즐 | 파티 전체 (회의) | 라운드당 병렬 1콜 | 토큰 or MCP | — |
| 선택이벤트 | 파티 전체 (회의) | 동일 | Prompt 카드 or 없음 | — |
| 훈련장 | 플레이어 | 없음 | Prompt/Skill 카드 3택1 | — |
| 아이템 상점 (MCP 마켓) | 플레이어 | 없음 | MCP 구매 (토큰) | — |
| 보물상자 | 플레이어 | 없음 | MCP 1 확정 | ✔ |
| 휴식 | 플레이어 | 없음 | 게이지·인벤토리 정리 | — |

- **탈옥·교섭·1대1 결투는 선출된 1기의 단독 무대** — 누가 가느냐로 판이 완전히
  달라진다 (셀레네의 언변 vs 가렛의 정공법). 담당은 플레이어가 아니라 **파티가 이동
  시작 시 인선 회의로 뽑는다** — 각자 자원/추천, 엔진이 결정론 집계(자원자 우선, 경합·
  부재·시간 초과 시 담당 적성 스탯 최고). 카드 장착이 인선까지 바꾼다: 「겁이 없다」를
  단 피오나가 결투에 자원하기 시작한다.
- 퍼즐·선택이벤트·인선이 **파티 회의 엔진 하나를 공유**한다 — 구현 면적 절약.
- 몬스터도 'Agent 키우기' 테마를 공격한다 (후보: 스팸 골렘, 환각 정령, 무한루프 슬라임,
  프롬프트 임프, 토큰 크롤러 — 확정은 §9).

## 6. LLM 아키텍처 원칙

1. **멤브레인.** 플레이어는 타이핑하지 않는다. 모든 LLM 입력은 구조화된 게임 요소
   (카드·시트·전장 상태)에서 엔진이 조립한다. 탈옥도 에이전트가 수행한다.
2. **귀속, 일관성 아님.** 모든 판단은 `because` 필드로 원인 카드 id를 인용한다.
   "같은 프롬프트 = 같은 행동"은 약속하지 않는다 — 카드로 소급되면 공정하다.
3. **의도만 LLM, 실행은 엔진.** 닫힌 선택지(structured output 강제) + 결정론 실행.
   응답 3초 초과 시 직업별 기본 행동 + 말풍선 "…" — 게임은 절대 LLM을 기다리며 멈추지 않는다.
4. **병렬 = 벽시계 1콜.** 유닛별 판단은 병렬 발사. 보스전은 적측 판단도 같은 병렬에 태운다.
5. **지연 은폐.** 인카운터가 타일별로 저작되어 있으므로, 이동 시작 시점에
   ① 인선 회의(1벽시계콜 — 발화는 걷기 중 말풍선으로 재생) → 엔진 결정론 집계 →
   ② 선출 유닛의 타일 첫 판단 **선발사**가 파이프라인으로 돈다. 벽시계 2콜이 걷는
   연출 뒤에 숨는다 (이동 시간은 `data/` 튜너블). 그 외 구간의 잡담은 디자인 타임에
   LLM으로 대량 생성한 풀에서 재생 ([성격 조합 × 최근 사건 버킷] 키) — 런타임 지연 0.
6. **프록시 경유 + 밸런스는 `data/`.** 클라이언트에 키 없음(팀원 B 레인). 모든 튜너블은
   데이터로.

## 7. 프레젠테이션 — 전투·이동 뷰 (확정: 횡스크롤)

**횡스크롤 라인 뷰(Darkest Dungeon식)로 확정 (07/25).** 검토했던 대안: 탑뷰 그리드
(오토체스류 — 그리드가 이동을 기대하게 하는데 우리 전투는 이동이 없고, 말풍선이 겹침),
쿼터뷰(FTK — 아이소 에셋 비용이 2인 3주에 과함).

확정 이유: **이동과 전투가 같은 화면**이다 — 걷다가 그 자리에서 대치하므로 씬 전환이
없고, 자동 전진 중 선발사한 판단이 도착 즉시 전투로 이어져 페이싱 전략(§6-5)과
맞물린다. 관전 게임의 생명인 말풍선·표정 가독성도 측면 라인이 가장 좋고, 에셋도
측면 일러스트 + 루프 배경으로 최소다.

```
 [가렛]  [피오나]  [셀레네]              [스팸 골렘]  [환각 정령]
    └ "물러서 있어, 피오나. 다음 일격은 내 방패가 받는다."
────────────────  던전 바닥 — 이동 시 배경만 스크롤  ────────────────
 카드 슬롯 / 게이지 / 토큰 HUD
```

## 8. 데모가 증명해야 할 것 (베이크오프 기준 — 브리프 §9 승계)

1. 고강도 카드 2–3장을 단 에이전트의 판단이 ① 예상 밖이면서 ② 카드로 소급 가능한가 —
   그 귀속이 재시도 욕구를 만드는가.
2. 이동 없는 턴제 전투에서 「겁이 많다」가 화면에 읽히는가 — 행동 선택 + 말풍선만으로.
3. 전진 → 이벤트 → 전진의 타일 리듬이 3–5분 관전을 버티는가.
