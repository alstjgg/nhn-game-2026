# Request-first v2 browser walkthrough

실제 v2 클라이언트를 deterministic mock provider로 한 라운드 완주한 화면이다.

1. `01-drawing.jpg`: 잠긴 부탁의 단서를 계속 보면서 그림으로 답하는 화면
2. `02-vlm-evidence.jpg`: 원본 그림 위 가시 근거와 판독 결과
3. `03-relationship-recorded.jpg`: 원본 실루엣 생명화, 정원 변화, 관계 기록

이 화면은 UI·렌더러·라운드 완주 검증용이며, 별도 `api-baseline` 폴더의 라이브 OpenAI
시간·토큰·응답과 혼동하지 않는다.
