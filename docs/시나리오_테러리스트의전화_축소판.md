> 이행. [원본 시나리오](./시나리오_테러리스트의전화.md)는 보존하며, **데모 저작의

## 1. 축소 원칙 — 페이퍼 테스트가 준 다섯 규칙

축소는 "덜어내기"가 아니라 **귀속을 명확하게 만들기**다. v2 실측에서 도출:

1. **게이트 하나 = 실패 원인 하나.** 각 게이트의 실패가 판단 1개 또는 결핍된
   사실 1개로 소급돼야 한다. (원본 G2·G3은 지휘권·수사·문서가 얽혀 귀속 불가)
2. **진실 하나 = 게이트 하나의 열쇠 + 기질 축 명시.** 사실 문장은 기질 조건이
   감시하는 축의 어휘로 쓴다 (V2 실패→V2″ 통과의 법칙). 문장마다 `targets`를 단다.
3. **단일 경로 금지.** 진실마다 발견 경로 ≥ 2. (v2에서 G1이 J2c 단일 경로에 묶여
   5런 전부 fail — 이 실수를 시나리오 층위에서 반복하지 않는다)
4. **미보유 정보를 주장하는 선택지 금지.** 근거가 없으면 옵션이 아예 안 보인다
   (visible_if 규율).
5. **서열을 시험하는 판단 지점에는 "둘 다 만족" 탈출구를 두지 않는다** (V4 교훈).
