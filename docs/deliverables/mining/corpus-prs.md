## Classification conventions

Classified from title / base branch / head branch only (no body or thread reads):

- **unit** — super-pipeline unit PRs: base branch matches `super/<run-timestamp>`; titles usually tagged `[uN]` / `[eN]` (a few untagged unit-lane fixes, e.g. #69, #77, share the base-branch convention).
- **integration** — super-pipeline integration/final PRs: title starts with `[run-<timestamp>]`; base is `main` or a staging branch. These PRs double as the run **dashboard/steer** surface — `[STEER]` direction comments land as issue comments here (visible as the high comment counts on #17, #33, #68, #110, #116). No separate dashboard-only PRs exist, so no distinct dashboard group.
- **single-agent** — head branch prefixed `codex/` or `claude/`: single-agent tool sessions outside super-pipeline (authored under human logins).
- **manual** — everything else (docs/, chore/, feat/, test/, concept/ branches): manual human/Claude-Code sessions.
