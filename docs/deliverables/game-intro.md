# 게임 소개 및 설명 문서

# 1. 게임 제목과 소개

## 제목

### 긴급상황대응실 운영자 임용을 축하합니다

## 한 줄 소개

> 당신은 현장에 나가지 않는다. 현장에 나갈 AI 요원이 **무엇을 알고 들어갈지**를 정하고,
> 같은 밤을 다시 시작한다.

## 상황

대설주의보가 내린 밤, 한내시립스포츠돔에서 천장이 처진다는 신고가 한 통 들어온다. 공기로
부풀려 세운 지붕이라 안에 있는 사람들은 두 명씩만 퇴장할 수 있는 회전문으로 빠져나와야 한다. 그런데
야간 당직자는 안에 아무도 없다고 말한다. 지붕은 어차피 내려앉는다. 남은 문제는 그때 몇 명이
아직 한내돔 안에 있느냐이다.

당신은 이 사건을 재구성한 모의 단말 앞에 앉은 신규 운영자다. 현장에 나가는 것은 당신이
파견한 AI 요원이고, 같은 시뮬레이션을 총 네 번 시행할 수 있다.

| | |
|---|---|
| 장르 | 텍스트 추리 × AI 에이전트 빌드 시뮬레이션 |
| 플랫폼 | 웹 (데스크톱 브라우저) |
| 플레이 시간 | 15분 내외 |

# 2. 게임 컨셉

이 게임은 세 가지 규칙 위에 서 있다.

**① 판단의 주체는 실행 중의 AI다.** 요원의 판단, 회선에 내보내는 무전, 근무가 끝난 뒤 쓰는
보고는 대본이 아니다 — 게임이 실행되는 동안 LLM이 생성한다. 요원에게 명령할 수 없고, 요원의
성향(어떤 상황에서 어떻게 판단하는지)은 화면에 드러나지도 않고 고칠 수도 없다. 요원을
움직이는 유일한 지렛대는 **요원이 아는 사실**이다. 아는 것이 달라지면 같은 전화를 받아도
판단이 달라진다.

**② AI에게 말을 걸 수 없다.** 게임 어디에도 텍스트 입력창이 없다. 플레이어가 AI에 닿는
길은 시뮬레이션이 스스로 만들어낸 문장을 골라 요원의 인수인계 사항에 배치하는 것, 그
하나뿐이다. 이것은 제약이 아니라 설계다 — 이 게임의 추리가 「AI를 어떻게 설득할까」가
아니라 **「이 요원은 무엇을 잘못 알고 있었고, 그것을 바로잡을 문장은 어느 기록에 있나」**
가 되도록. 요원이 받는 모든 문장은 그 세계의 누군가가 실제로 말했거나 기록한 것이다.

**③ 실패한 시행이 광석이다.** 시행이 끝나면 문서 두 개가 남는다 — 시뮬레이션이 남긴 객관적
**현장 기록**과 요원이 직접 쓴 **요원 보고**. 두 문서는 합쳐지지 않고, 둘 사이의 차이가 곧
단서다. 여기서 문장을 채굴해 다음 요원의 인수인계 네 칸에 배치한다. 사망자를 줄이지 못한
회차도 문장을 남기고, 깊이 진행된 회차일수록 많이 남긴다. 이 게임에서 쌓이는 것은 캐릭터의
능력치가 아니라 **요원에게 건넬 수 있는 정보의 정확도**다.

세 규칙이 한 판에서 만나는 모습은 첫 갈림길에서 바로 보인다 — 아무것도 넘겨받지 않은 요원은
「안에는 아무도 없다」는 당직자의 말을 들은 대로 믿고 신고를 가볍게 접수한다. 지난 시행의
기록에서 그 말을 의심하게 하는 문장을 찾아 다음 요원에게 쥐여 보내면, 같은 전화를 받은
요원이 다르게 움직이고 닫혀 있던 갈림길이 열린다.

# 3. 게임 방법

## 3.1 목표

**하나의 사고 상황을 반복 시행하며, 사망자 수를 최소화한다.**

> 운영자는 흩어진 기록을 모아 현장 요원에게 전달하고, 이것이 생환자 수를 결정합니다.
> — 게임 내 강평 화면

결과는 합격과 불합격으로 갈리지 않는다. **누가 살아 나왔는지**로 갈리기 때문에, 사망자 수가
같아도 그 안에서 벌어진 일은 다르다.

## 3.2 진행 순서

로그인하면 브리핑 두 장이 지나가고 데스크가 열린다. 그다음부터는 아래 네 단계가 반복된다.

```
① 작성   AGENT FILE — 채굴한 문장을 인수인계 사항의 네 칸에 배치한다
   ↓        (첫 시행에는 배치할 문장이 없다. 그대로 파견한다)
② 파견   DEPLOY — 요원이 현장으로 떠나고, 이후로는 개입할 수 없다
   ↓
③ 관전   LIVE FEED — 18시 38분부터 사건이 한 줄씩 올라온다. 요원의 무전과 판단도 여기 찍힌다
   ↓
④ 분석   REPORTS — 문서 두 개가 남는다. 실패 원인을 짚고 문장을 채굴한다
   ↓
   ①로 — 시행 한 번을 소모한다
```

**시행은 모두 네 번이다.** 1회차는 개입 없이 그날을 그대로 지켜보는 회차이고, 이후 세 번을
다시 시행할 수 있다.

## 3.3 조작

**마우스 클릭이 전부다. 게임 어디에도 키보드로 글자를 넣는 곳은 없다(2장 ②).**

| 조작 | 하는 일 |
|---|---|
| **문장 클릭** (REPORTS 안) | 그 문장을 채굴해 인수인계 사항의 빈 칸에 **한 번에** 배치. 배치할 수 없는 문장이면 거절 사유가 잠깐 표시 |
| **해제** (AGENT FILE 안) | 배치한 문장을 칸에서 제거 |
| **페이지 넘김 `‹` `›`** | AGENT FILE은 요원 한 명당 한 페이지. 지난 요원에게 무엇을 건넸는지 확인 가능 |
| **DEPLOY** | 인수인계를 확정하고 요원을 파견. 되돌릴 수 없으므로 확인 창 표시(`파견` / `취소`) |

그 밖의 조작: 창 드래그(데스크 배치 이동), ♪(음소거), 건너뛰기(브리핑·표지 연출 생략).

**인수인계 사항은 최대 네 칸이다.** 네 칸이 다 차면 더 배치할 수 없고, 기존 문장을 해제해야
넣을 수 있다. **무엇을 빼고 무엇을 넣을지** — 어느 문장이 요원의 오해를 바로잡는 사실이고
어느 문장이 그럴듯한 미끼인지 가려내는 것 — 이 이 게임의 핵심이다.

## 3.4 화면

데스크에는 창이 셋 있다.

- **REPORTS** — 시행이 끝나면 쌓이는 문서 두 개. **현장 기록**(객관적 사실)과 **요원
  보고**(요원이 직접 쓴 서술). 요원이 무엇을 잘못 알고 있었는지는 요원이 쓴 문장에만
  드러난다. 문장을 채굴하는 곳도 여기다.
- **LIVE FEED** — 관전 화면. 사건이 게임 안 시각에 맞춰 한 줄씩 올라오고, 요원이 회선에
  내보낸 무전도 함께 찍힌다. 이 동안에는 개입할 수 없다.
- **AGENT FILE** — 요원의 파일. 인수인계 사항 네 칸과 호출부호(ECHO-1, ECHO-2 …).
  요원마다 한 페이지씩 쌓인다.

현장에 나가 있는 것은 요원이고, 등장인물은 전부 회선 너머에 있다. 플레이어도 요원도 사고
현장을 직접 보지 못한다. 화면에 올라오는 모든 것은 누군가가 회선으로 전한 말이거나 기록으로
남긴 문장이다.

## 3.5 종료 조건

**엔딩은 두 가지이고, 어느 쪽이든 강평 화면 세 장으로 끝난다.**

| 엔딩 | 조건 | 화면 |
|---|---|---|
| **성공** | 한 시행이 **사망자 0명**으로 종료 (몇 회차든 무관) | 시뮬레이션 종료 → 훈련 강평 → **모의 과정 완료 · 임용 확정** |
| **실패** | 네 번을 다 쓰고도 사망자 0명에 미도달 | 시뮬레이션 종료 → 훈련 강평 → **모의 과정 완료 · 평가 보류** |

4회차에 성공해도 성공이다. 남은 시행이 0이 되는 것과 실패는 다르다.

전원을 내보내는 길은 하나가 아니다. 서로 다른 두 갈래로 도달할 수 있다.

# 4. 실행 방법

**설치할 것이 없다. 웹 페이지에 접속하면 바로 플레이된다.**

1. 5장의 링크를 연다.
2. 로그인 화면에서 안내대로 진행하면 브리핑 두 장이 지나가고 데스크가 열린다.
3. 첫 시행에는 인수인계에 배치할 문장이 없다. **그대로 DEPLOY를 누르면 된다.** 개입하지
   않았을 때 무슨 일이 벌어지는지 먼저 보는 것이 1회차의 목적이다.

**권장 환경**

- **데스크톱 브라우저** (Chrome · Edge · Safari · Firefox 최신 버전). 모바일과 태블릿은
  미지원
- 설치, 다운로드, 계정 생성, 결제, 유료 라이선스 불필요
- 새로고침 시 새 회차 시작
- 소리는 있으나 플레이에 필수 아님. 음소거는 ♪ 버튼
