- A–D 원본 코너 평균이 모두 `R>180, B>180, G<100`을 통과했다.
- 모든 후보가 4×3의 12개 셀을 채웠다.
- 최종본의 불투명 기술 마젠타 잔여 픽셀은 A 1개, B 2개, C 0개, D 0개다.

`A.png`–`D.png`는 비교용 최종본, `raw/`는 해당 API 원본이다. 전체 프롬프트와
