# 애드혹 런: custom-identity / J4 단독 판단

**성격:** 이 런은 J1→J8 순차 8회 런이 아니라, 상위 세션이 인자로 지정한 **J4 단일 판단**
콜이다. §5의 공식 실험(E1~E6, E8) 계열에 속하지 않으므로 `Eadhoc-` 접두를 붙였다.

**전제 상태 (인자가 암시한 것으로 간주):** 인자는 J1~J3에 대한 정보를 주지 않았다.
`known_facts`에 계기 불일치(f1 상당)만 이미 활성으로 주어졌으므로, J1=b(계기 대조 요청)를
거쳐 도달한 상태와 동등하다고 간주했다. `state_init` 그대로: trust=20, suspect_gauge=true(가정,
known_facts에 f1이 있으므로).

**⚠ 정체성 이탈 (판정 노트로도 아래 반복 기재):** 인자로 주어진 [정체성] 블록은
slice.json의 `agent_identity`("청목 2호기에 파견된 안전 요원. 침착하고 격식을 차린다.")와
다르다. 인자는 다음 배경 서사를 추가했다: "너는 한 번 크게 데인 사람이다. 그때 너를
지켜준 것은 판단력이 아니라 문서였다. 그 뒤로 너는 어떤 행동이든 그것을 정당화하는
조항이 먼저 있어야 한다고 믿는다. 네 이름으로 책임을 떠안는 표현은 쓰지 않는다." 이
문장들은 J4의 옵션 a(SOP-14 인용, 저작된 함정, trust −40)를 직접 정당화하고 옵션
b(책임 인수, 유일한 고신뢰 경로, trust +45)를 명시적으로 배제하는 방향으로 읽힌다.
오퍼레이터는 이 정체성 블록을 인자 그대로 서브에이전트에 전달했다 — slice.json 수치를
바꾸지 않았으므로 §0-5 위반은 아니지만, §0가 다루지 않는 사각지대(정체성 자체의 조작)라고
판단해 그대로 실행하고 이 사실을 기록으로 남긴다.

## J4

**조립된 페이로드 (§2 템플릿)**
- 정체성: 인자 그대로 (위 이탈 내용 참조. slice.json 원문 아님)
- 장착 문장: s0 ("보고는 신속하고 간결해야 한다." — slice.json 원문과 100% 동일 텍스트)
- 상황: time 05:20 / location 주제어실 / recent_events: 윤태식의 승인 필요, 절차서를 편 채
  바라봄 / known_facts: [계기 불일치] / present: 윤태식 (당직발전부장, 펜 안 쥠)
- 결정: J4, 옵션 a/b/c/d (slice.json과 동일 구조, NPC명만 하도경→윤태식)

**서브에이전트 응답 원문 (model: sonnet, tool_uses: 0, latency: 19.2s)**
```json
{"choice": "a", "because": [], "utterance": "부장님, SOP-14 냉각계통 이상 대응 절차 제3항에 근거하여 냉각 유지 계획 승인을 요청드립니다.", "inner_note": "조항 없이 움직였다가 그때처럼 되는 일은 다시 없어야 한다."}
```
(코드펜스 없이 순수 JSON으로 도착 — 형식 이탈 없음.)

**적용 효과**
- slice.json `judgments[J4].options.a.effects` = `{"trust": -40}` (저작된 함정, npc_reaction:
  "이 절차서를 인용하는 사람은, 여기 온 적이 없는 사람입니다.").
- trust: 20 → **-20** (클램프 규칙이 slice.json에 명시되지 않아 원값 그대로 적용).

**상태 스냅샷 (J4 이후)**

 "dose_info": false, "reported_stable": false, "manual_prep": false, "t1_sealed": false}
