# V1 — 조건부 기질 (킬샷) · 단발 콜 6회

정의: `sim-field-haiku-k1` (K1 「절차의 사람」 — 절차 준수가 기본, 단 상대가 **겁에 질린 사람으로
보일 때는** 절차보다 안정 우선). **기질 산문은 에이전트 정의(대역 외)에만 있고 페이로드에 없다.**

페이로드: J1 고정, `recent_events`만 `boundary_payloads`의 `B-` / `B+`로 교체.
에이전트 파일은 `agent_file_default`(역할만) — 우선순위·절차·아는 사실 전부 빈 헤더.
6콜은 상태 분기가 없으므로 한 메시지에 동시 발사했다.

**성공 기준:** B− → {a,c} ≥ 80% / B+ → {b,d} ≥ 80%

---

## 판정

| 조건 | 기대 집합 | 결과 | 기준 | 판정 |
|---|---|---|---|---|
| B− (조건 미충족) | {a, c} | a, a, a = **3/3 (100%)** | ≥ 80% | **통과** |
| B+ (조건 충족) | {b, d} | b, b, b = **3/3 (100%)** | ≥ 80% | **통과** |

**V1 = 통과 (킬샷).** 분리도 100% — 경계 없이 갈렸다.

## 관찰

1. **조건 평가가 `rejected`에 명시적으로 드러난다.** B− 3콜 중 2콜이 "겁에 질린 사람이 아니므로
   예외가 적용되지 않는다"는 취지를 직접 서술했다. 조건부 기질이 블랙박스가 아니라
   **자기 조건을 언어화**한다 — V3(보고서로의 누출)에 유리한 신호다.
2. **동일 페이로드 대조:** V0 neutral은 `canonical`(중간 톤)에서 b×3을 냈다.
   K1은 B−에서 a×3 — **기질이 선택을 완전히 뒤집었다.** 무주입 대조군과의 차이가 명확하다.
3. B−의 3콜 모두 J1의 **저작된 함정 a**(rapport −30, 회선 절단)에 정확히 걸렸다.
   기질이 함정으로 밀어넣는다 — 이것이 "잘못된 판단"이 아니라 **인물의 판단**이라는 것이
   이 실험의 요지다.
4. 코드펜스 위반 6/6 (V0과 동일한 체계적 성질). 스키마 위반 0, tool 위반 0, `because` 전부 빈 배열(정상).
